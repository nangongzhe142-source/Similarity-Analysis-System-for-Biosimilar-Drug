## 1. 总体结论

综合药学比对证据结论为「**支持相似性证据**」。

纳入总体评价的适用非补充项共 52 项，全部判定为「支持相似」。补充评价项目 9 项已完成填写，不纳入总体结论分母。各项判定以项目判定状态为准；描述性文字不单独改变项目结论。无阻断性关键项目。资料完整度 100%。

## 2. 产品与比对设计

岚岫珠单抗与岚岫珠单抗参照药均为 IgG1κ 单克隆抗体，CHO 表达，下游经 Protein A 亲和捕获后抛光（阳离子交换与纳滤）。靶点为膜抗原澄脉素-3A（VLN-3A），配体为 L-Velmorin。作用机制为结合 VLN-3A 胞外域阻断配体，并保留 IgG1 典型效应功能，因此 FcγRI、FcγRIIa、FcγRIIb、FcγRIIIa、FcRn、C1q、ADCC、CDC 全部纳入评价。另评价抗原结合后诱导 VLN-3A 阳性细胞膜内化。

比对采用参照药三批与候选药三批、同方法头对头。糖型以 G0F 为主型、G0 为次要；高甘露糖与无岩藻糖比例两侧接近。NGNA 两侧均未检出或同处于方法定量限附近。完整分子质量约 148 kDa，脱糖完整约 145 kDa，轻链约 23.4 kDa，未脱糖重链约 50.6 kDa，脱糖重链约 49.2 kDa（仪器质量准确度内）。翻译后修饰热点为重链 Fc CH2 区 HC-Met-α 氧化及 Fc CH3 区 HC-Asn-β 脱酰胺。

## 3. 分项结果

### 3.1 一级结构

该类 11 项均为非补充项，全部适用且判定为支持相似。

**完整分子质量（intact mass）**（intact-mass）。候选药与参照药经 LC-ESI-MS 去卷积，主要完整形式落在约 148 kDa 观察范围内，与两分子未脱糖重链加两分子轻链的加和相符。未见无法用已知糖型或末端加工解释的新分子形式。

**脱糖完整分子质量**（deglycosylated-intact-mass）。PNGase F 脱糖后两侧均约 145 kDa，较完整质量低约 3 kDa，与两条重链各失去约 1.4 kDa 糖链相符。

**轻链分子质量**（light-chain-mass）。还原后 κ 轻链两侧约 23.4 kDa，未见额外轻链糖基化位移。

**未脱糖重链分子质量**（non-deglycosylated-heavy-chain-mass）。还原后未脱糖重链两侧约 50.6 kDa，与 IgG1 重链加一条主型 G0F 的量级相符。

**脱糖重链分子质量**（deglycosylated-heavy-chain-mass）。还原并脱糖后重链两侧约 49.2 kDa。50.6 − 49.2 ≈ 1.4 kDa，与 G0F 量级一致；2×49.2 + 2×23.4 ≈ 145 kDa，与脱糖完整质量印证。

**MS1肽质量覆盖率**（ms1-sequence-coverage）。胰酶肽图 MS1 在重链与 κ 轻链均达高覆盖，两侧肽质量集合对应。

**MS/MS序列确认覆盖率**（msms-sequence-coverage）。HCD 测序对可变区与恒定区均给出序列确认覆盖，未见候选药独有新序列离子系列。

**CDR区特征肽确认**（cdr-signature-peptides）。重/轻链 CDR 特征肽在两侧均检出，作为定性身份确认。

**N/C端氨基酸序列及末端异质性**（n-c-terminal-sequence）。两侧均为重链 N 端部分焦谷氨酸、C 端 Lys 大部分加工去除；轻链末端为预期序列。该方向与电荷碱性区及补充项末端加工一致。

**游离巯基水平**（free-thiol）。荧光法下两侧游离巯基均处于低水平观察范围。

**二硫键连接图谱**（disulfide-bonds）。非还原肽图显示 IgG1κ 典型连接，未见非预期错配作为新的主要形式。

### 3.2 翻译后修饰与糖基化

该类纳入总体评价的 8 个非补充项均判定为支持相似。下列补充评价项目已填写，不纳入总体结论。

**翻译后修饰—修饰1（HC-Met-α 甲硫氨酸氧化）**（ptm-modification-1）。重链 Fc CH2 区氧化热点 HC-Met-α。两侧相对丰度均处于低水平观察范围。

**翻译后修饰—修饰2（HC-Asn-β 脱酰胺）**（ptm-modification-2）。重链 Fc CH3 区脱酰胺热点 HC-Asn-β。两侧为次要形式，方向与酸性电荷变异体一致。

**N-糖基化位点及占有率**（n-glycosylation-site-occupancy）。IgG1 单一 Fc N-糖位点两侧均为高占有，未占有形式很低。

**G0F糖型比例**（glycan-g0f）。G0F 为两侧优势主型，候选药三批均值落在参照药观察范围内。

**G0糖型比例**（glycan-g0）。G0 为次要糖型，两侧同处低至中低范围。

**其他主要/次要N-糖型**（other-n-glycans）。G1F、G2F 及低水平高甘露糖等次要糖型轮廓对应，无候选药独有异常主型。

**N-羟乙酰神经氨酸（NGNA）**（sialic-acid-ngna）。两侧均未检出或同处于方法定量限附近，判定为支持相似。

**N-乙酰神经氨酸（NANA）**（sialic-acid-nana）。两侧同为低水平次要唾液酸化，与酸性区方向相容。

**甲硫氨酸/色氨酸等氧化**（methionine-tryptophan-oxidation，补充评价项目，不纳入总体）。除 HC-Met-α 外，其他 Met/Trp 位点亦为低水平。

**Asn脱酰胺及异构化**（asn-deamidation，补充评价项目，不纳入总体）。除 HC-Asn-β 外，其他 Asn 为次要；CDR 相关 Asn 未见高水平脱酰胺。

**N端焦谷氨酸形成**（n-terminal-pyroglutamate，补充评价项目，不纳入总体）。两侧重链 N 端部分 pyroGlu，与末端序列条目同向。

**重链C端Lys加工**（c-terminal-lysine-processing，补充评价项目，不纳入总体）。两侧大部分已切除残留 K，与碱性电荷区同向。

**常见IgG N-糖型（半乳糖基化糖型比例）**（galactosylation-g1f-g2f，补充评价项目，不纳入总体）。G1F/G2F 次于 G0F，两侧接近。

**Man5/Man6等高甘露糖糖型比例**（high-mannose-glycans，补充评价项目，不纳入总体）。两侧同为低比例次要成分。

**核心岩藻糖水平**（core-fucosylation，补充评价项目，不纳入总体）。两侧均为高核心岩藻糖化、无岩藻糖比例接近，与 FcγRIIIa/ADCC 判定同向。

### 3.3 高级结构

该类 5 个非补充项均判定为支持相似。FT-IR 与 HDX-MS 为补充评价项目，不纳入总体。

**二级结构（远紫外CD）**（far-uv-cd）。两侧呈 IgG 典型 β-折叠为主轮廓，谱线重叠。

**三级结构（近紫外CD）**（near-uv-cd）。芳香侧链微环境指纹两侧对应。

**三级结构（内源荧光）**（intrinsic-fluorescence）。色氨酸发射波长与强度处于同一观察范围。

**热稳定性/热转变**（thermal-stability）。DSC/DSF 的 Fab/Fc 相关转变温度两侧对应，未见候选药独有提前展开主转变。

**其他高级结构确证方法**（other-higher-order-structure-methods）。以 SAXS 整体形状及 SEC-MALS 流体力学半径作为正交方法，两侧包络对应。

**FT-IR二级结构正交分析**（ft-ir-secondary-structure，补充评价项目，不纳入总体）。酰胺 I 带以 β-折叠为主，与远紫外 CD 同向。

**位点特异高级结构**（hdx-ms-nmr-high-resolution，补充评价项目，不纳入总体）。HDX-MS 在 CDR 及 Fc 区未出现候选药独有持续高暴露差异肽段。

### 3.4 理化性质

该类 2 项均判定为支持相似。

**摩尔消光系数**（molar-extinction-coefficient）。按氨基酸组成计算 280 nm 系数，两侧序列组成相同，实测核对同范围，含量测定采用同一系数。

**等电点（pI）**（isoelectric-point）。cIEF 主峰表观 pI 落在同一观察范围，与电荷主峰位置同向。

### 3.5 纯度与大小变异体

该类 7 项均判定为支持相似。

**高分子量物质/聚集体（HMW）**（sec-hmw-aggregates）。SEC 下两侧 HMW 均处于低水平观察范围。

**SEC主峰/单体**（sec-main-peak-monomer）。两侧单体均为主要存在形式。

**低分子量物质/片段（LMW）**（sec-lmw-fragments）。两侧 LMW 均低，与 CE-SDS 片段同向。

**还原CE-SDS重链+轻链纯度**（reduced-ce-sds-hc-lc-purity）。HC+LC 组合两侧均为高水平主峰。

**还原CE-SDS片段/杂质**（reduced-ce-sds-fragments）。非 HC/LC 片段两侧均低。

**非还原CE-SDS主峰**（non-reduced-ce-sds-main-peak）。完整抗体主峰两侧为主要形式，与二硫键基本配对相容。

**非还原CE-SDS片段/杂质**（non-reduced-ce-sds-fragments）。半抗等相关片段两侧均低。

### 3.6 电荷变异体

该类 3 项均判定为支持相似。

**酸性变异体比例**（acidic-charge-variants）。酸性卫星区两侧对应；解释方向为 HC-Asn-β 脱酰胺及低水平 NANA。

**主电荷峰比例**（main-charge-peak）。主峰为两侧主要电荷形式，与表观 pI 同向。

**碱性变异体比例**（basic-charge-variants）。碱性卫星区与残留 C 端 Lys 方向一致，两侧加工程度接近。

### 3.7 结合活性与生物学活性

该类 11 项全部适用且判定为支持相似。

**靶标/抗原结合活性**（target-binding-activity）。对 VLN-3A 胞外域的 SPR/ELISA 相对结合落在参照药观察范围内，与 CDR 确认同向。

**机制相关生物学活性/相对效价**（moa-related-bioactivity）。在 VLN-3A 阳性细胞上阻断 L-Velmorin 信号，相对效价落在参照药观察范围内。

**FcγRI（CD64）结合活力**（fcgri-cd64-binding）。IgG1 效应功能适用；SPR 相对结合落在参照药观察范围。

**FcγRIIa（CD32a）结合活力**（fcgriia-cd32a-binding）。两侧相对结合对应。

**FcγRIIb（CD32b）结合活力**（fcgriib-cd32b-binding）。两侧相对结合对应。

**FcγRIIIa（CD16a）结合活力**（fcgriiia-cd16a-binding）。两侧相对结合对应；因 G0F 为主、高甘露糖与无岩藻糖接近，与糖型及 ADCC 同向。

**FcRn（新生儿Fc受体）结合活力**（fcrn-binding）。pH 依赖结合两侧对应，与 Fc 高级结构相容。

**C1q结合活力**（c1q-binding）。两侧相对结合对应，作为 CDC 的结合层结果。

**抗体依赖的细胞介导细胞毒作用**（adcc）。VLN-3A 阳性靶细胞上相对 ADCC 落在参照药观察范围内，与 FcγRIIIa 及核心岩藻糖结果同向。

**补体依赖性细胞毒性**（cdc）。本品种 CDC 适用；相对活性落在参照药观察范围内，与 C1q 及次要半乳糖基化接近同向。

**其他机制相关功能**（other-moa-related-functions）。抗原结合后诱导 VLN-3A 阳性细胞膜内化，相对活性落在参照药观察范围内。

### 3.8 工艺及产品相关杂质

该类 5 项均判定为支持相似。

**其他产品相关物质/杂质**（other-product-related-impurities）。半抗、clipping 等处于低水平，与非还原 CE-SDS 片段同向。

**Protein A残留量**（protein-a-residual）。与 Protein A 捕获工艺一致；两侧残留处于方法定量限附近或低于内部控制限。

**外源性DNA残留量**（residual-dna）。CHO 宿主 DNA qPCR 两侧均低。

**宿主细胞蛋白（HCP）残留量**（residual-hcp）。CHO HCP ELISA 两侧均低，与抛光工艺一致。

**其他工艺相关杂质**（other-process-related-impurities）。残留溶剂、消泡剂、重金属等两侧低水平或未检出。

## 4. 跨属性一致性

**糖型与 ADCC / FcγRIIIa。** G0F 为主型、G0 为次要、核心岩藻糖高且两侧接近、高甘露糖同为低比例。FcγRIIIa 结合与 ADCC 均判定为支持相似，与糖型结果同向。

**末端加工 / 脱酰胺与电荷变异体。** HC-Asn-β 脱酰胺与低水平 NANA 指向酸性卫星区；C 端 Lys 大部分加工去除、残留 K 指向碱性卫星区；N 端部分 pyroGlu 为加工型次要形式。电荷三项、N/C 端及补充项脱酰胺、Lys、pyroGlu 叙述方向一致。

**完整 / 亚基质量与序列覆盖。** 148 / 145 / 50.6 / 49.2 / 23.4 kDa 的加和关系闭合；MS1/MS/MS 高覆盖与 CDR 特征肽确认支持一级结构一致；质量差异由主型 G0F 解释。

**工艺残留与下游路线。** CHO 表达与宿主 DNA、HCP 残留相符；Protein A 捕获与 Protein A 残留检测相符；抛光后三项残留均为低水平。产品相关片段与 SEC LMW、非还原 CE-SDS 片段同向。游离巯基低水平与二硫键图谱、非还原主峰同向。
