## 2. 在线数据流

`mzML/RAW + FASTA → MetaMorpheus 可变修饰检索 → 1% FDR → FlashLFQ 肽段定量 → Pyteomics/FASTA 位点映射 → BioCompare 多批参照区间层 → 页面结果`

统一异步接口：

- `POST /api/jobs`：上传候选药、参照药肽图及 FASTA
- `GET /api/jobs/{id}`：查询进度及质量阻断状态
- `GET /api/jobs/{id}/result`：获取机器可读结果
- `GET /calculation-units`：查看计算单元、适配器及在线引擎状态

输入角色固定为 `reference`、`candidate`、`fasta`，任务目录按项目、模块、任务 ID 隔离。原生输出、命令日志和结果均在任务目录留痕。

## 3. 四项修饰配置与证据边界

- PTM-01：M 氧化 `+15.994915 Da`；W 氧化使用 MetaMorpheus 内置修饰；页面按蛋白位点显示相对丰度并标记 M252/M428 热点。
- PTM-02：Asn 脱酰胺 `+0.984016 Da`。标准 HCD 不能凭该质量偏移区分 Asp 与 isoAsp，页面强制显示高风险证据边界；必须补充 ETD/ECD、特异酶法或其他正交证据后才能声称 isoAsp 已鉴别。
- PTM-03：蛋白 N 端 Q `-17.026549 Da`、E `-18.010565 Da`。只有额外提供适合完整/亚基去卷积的质量谱时，才可加入 UniDec 正交证据。
- PTM-04：肽图输出含 K/缺 K 末端肽比例；0K/1K/2K 可显示为二项推算，但明确标记其不能替代 UniDec 亚基/完整质量直接去卷积。

UniDec 页面引用：Marty et al., *Analytical Chemistry* 2015, DOI `10.1021/acs.analchem.5b00140`。

## 6. 正式样品使用前要求

正式验证应上传抗体候选药和至少三批参照药肽图 mzML，以及与样品一致的抗体 FASTA。若需原始 Thermo RAW，应先由用户在受控环境完成厂商许可确认；当前 MetaMorpheus 1.1.7 CLI 不接受需求描述中的 `--acceptThermoLicence` 参数，因此适配器不会发送一个不存在的命令行参数。

平台只标记位点丰度、参照区间符合性和证据风险，不自动给出生物相似性最终结论。
