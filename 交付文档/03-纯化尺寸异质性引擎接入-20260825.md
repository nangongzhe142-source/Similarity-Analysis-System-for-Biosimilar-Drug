日期：2026-08-25  
范围：PUR-01～PUR-07。

## 1. 引擎部署

- hplc-py 0.2.8：安装于 BioCompare `.venv`。
- chromConverter 0.9.1：安装于 `D:\BioCompareEngines\R-library`，Rscript 为 `D:\BioCompareEngines\R-4.6.1\bin\Rscript.exe`。
- HappyTools 0.0.2 源码本体：`C:\Users\MI\bioTools\HappyTools`，固定复验提交 `728224c79dcc8841729fe4b32203784d30dda9fb`。

chromConverter 为 GPL-3.0，仅由独立 Rscript 子进程调用。HappyTools 官方项目没有稳定的命令行入口，因此平台用独立 Python 子进程加载其官方 `HappyTools.bin.chromatogram.Chromatogram` 类完成时间校准；没有复制或重写其算法。hplc-py 在服务器 Worker 中进行基线校正、峰检测与EMG拟合，浏览器不执行计算引擎代码。

## 2. 公共链路

`厂商色谱文件/CE ASCII或CSV → chromConverter（非CSV时）→ canonical CSV → HappyTools时间校准 → hplc-py峰检测/EMG拟合/面积归一化 → 可配置峰窗分组 → BioCompare多批参照区间与风险标记`

统一接口：

- `POST /api/jobs`
- `GET /api/jobs/{id}`
- `GET /api/jobs/{id}/result`
- `GET /calculation-units`

任务工作目录、输入、日志、原生中间产物和结果按项目/模块/任务ID隔离；产物下载沿用既有白名单机制。

## 3. 业务映射

- PUR-01：HMW面积%；候选药偏高显示聚集风险提示。
- PUR-02：SEC主峰/单体面积%。
- PUR-03：LMW面积%；候选药独有峰高于LOQ时标记“待MS鉴定”。
- PUR-04：还原CE-SDS LC+HC纯度，并输出LC/HC比与NGHC%。
- PUR-05：还原CE-SDS LC/HC窗口外片段/杂质%。
- PUR-06：非还原CE-SDS主峰面积%。
- PUR-07：非还原CE-SDS主峰外片段/杂质%。

峰窗通过页面JSON配置传入。SEC使用HMW/MAIN/LMW，典型还原CE-SDS使用LC/HC/NGHC，非还原使用MAIN；未命中窗口的CE峰归入IMPURITY。LOQ、新峰匹配容差、主峰半窗均为任务参数。CEVal没有可自动调度CLI，仅在页面标记为人工复核参考。
