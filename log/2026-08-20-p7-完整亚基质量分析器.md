## 一、这是否接入了真实分析软件（实机核查）

**核查起因**：用户质疑本模块可能是「自己写的一段并不实际可用的东西」。以下全部为实机输出，非推断。

### 1.1 计算内核是第三方编译软件，不是自写算法

| 项 | 实测值 |
|---|---|
| pyOpenMS 版本 | **3.5.0**，`.venv/lib/site-packages/pyopenms/__init__.py` |
| UniDec 版本 | **8.2.1** |
| UniDec 计算内核 | **`unidec/bin/unidec.exe`，306,176 字节**，SHA-256 前 32 位 `0f3f15d10fa249da8190dacd12db4253` |
| 去卷积实际执行方式 | UniDec 以 `System Call` 启动上述 `.exe` 子进程 |

理论质量由 `pyopenms.AASequence.getAverageWeight()` 计算，去卷积由 `unidec.exe` 执行。本仓库代码只做输入准备、参数设置与结果判定，**没有自写质量计算或去卷积算法**。

### 1.2 能读真实仪器 mzML

| 文件 | 体积 | 读取结果 |
|---|---|---|
| `tiny.mzML` | 0.03 MB | 4 张谱 |
| `small.mzML` | 6.63 MB | 236 张谱（MS1 183），谱 0 有 1672 个峰，m/z 360.696–1473.297 |
| `Metabolomics_1.mzML` | 8.48 MB | 1052 张谱 |
| **`PXD063988` 胰酶消化真实抗体数据** | **702.0 MB** | **33,039 张谱**；谱 0 = MS1 @ RT 0.15 s；谱 16519 = MS2 @ RT 1890.89 s，829 个碎片峰 |

702 MB 文件用 `OnDiscMSExperiment` 流式索引读取（4.0 s 打开），不整体载入内存。

### 1.3 全链路在真实数据上跑通

真实 `small.mzML` → pyOpenMS 读取 → 183 张 MS1 平均 → 22,781 点合并谱 → `unidec.exe` 去卷积 → **检出 17 个质量峰，主峰 17021.0 Da，耗时 1.05 s**。

## 二、核查中发现并修复的两个真实缺陷

### 缺陷 1：mzML 根本无法进入分析（已修复）

P7 初版的 `run_uploaded_spectra` 只调用 `load_text_spectrum`（两列文本），**没有任何 mzML 读取路径**。也就是说当时的模块只能分析两列 txt，真实质谱文件进不来。

修复：新增 `mzml_reader.py`，`spectrum.load_spectrum()` 按扩展名分派 mzML/mzXML 与文本谱。

顺带实测确认了一个非推测的约束：**pyOpenMS 对中文路径直接抛 `RuntimeError: IO error for file`**。因此所有原生读取前一律 ASCII 暂存（D22），该行为有专门测试锁定。

### 缺陷 2：拟合质量再差也会被当成实测质量输出（已修复）

真实 `small.mzML` 去卷积得到 **R² = −10.07**（因为它是肽段 LC-MS 谱，本就不含单一蛋白电荷包络），而当时代码仍照常输出「主峰 17021.0 Da」并进入规则判定。这正是「把软件跑得出来的数字当成科学结论」的典型failure mode。

修复：新增下限 `MIN_DECONVOLUTION_R_SQUARED = 0.9`，低于下限时 `outcome/verdict` 强制 `REVIEW`，**不输出实测质量结论**，且措辞明确为「不构成质量一致或不一致的证据」。

对照实测：合成 BSA 电荷包络 R² = **0.9998**（通过），真实肽图 MS1 平均谱 R² = **−10.07**（拦截）。

## 四、当前能力边界（不夸大）

| 能力 | 状态 |
|---|---|
| 读真实 mzML / mzXML（含 700 MB 级） | ✅ 实机通过 |
| 两列文本谱（UniDec 官方谱格式） | ✅ |
| pyOpenMS 理论质量 + UniDec 去卷积 | ✅ 第三方软件实机执行 |
| 去卷积拟合质量门禁 | ✅ R² < 0.9 拒绝出质量结论 |
| 厂商 RAW（Thermo） | ⏳ 转换器已实现，pwiz 镜像拉取未完成 |
| 厂商 WIFF（SCIEX） | ❌ 未接（`PXD054948` 为 WIFF+scan 配对） |
| **真实抗体完整质量科学验证** | ❌ **未完成**。已下载的真实数据（PXD063988）是**胰酶肽图 LC-MS/MS**，不是完整分子量谱；工作区仍无真实的完整/亚基质量原始数据 |
| 质量搜索区间自动推断 | ❌ 需调用方传入（默认 60–75 kDa 为 BSA 量级，抗体约 148 kDa 需显式指定） |

**关键诚实结论**：软件链路已在真实仪器数据上跑通，但**「用真实抗体完整质量谱复现 148 kDa 级去卷积」这一科学验证尚未完成**，因为该类型的真实数据在工作区不存在（P0 §4.6 已记录，P1 下载的三个数据集均为肽图/二硫键类型）。当前 golden test 的科学正确性依据仍是合成谱的已知真值。
