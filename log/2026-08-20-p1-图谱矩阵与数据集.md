## 4. 分析参数

- PRIDE 项目查询：`GET /projects/{accession}`，文件分页 `GET /projects/{accession}/files?pageSize=100&page=N`；
- 关键词检索：`GET /search/projects?keyword=…&pageSize=15`，检索词 `NISTmAb`、`trastuzumab biosimilar`、`adalimumab biosimilar`、`intact antibody deconvolution`；
- 体积探测：`Range: bytes=0-1023`，读取响应头 `Content-Range` 的总长度；
- FASTA 交叉比对：去除非字母字符后逐残基比较，定位首个分歧位点；
- 平均质量核算：标准残基平均质量表 + 水 18.0153 Da，全巯基（未成二硫键）态。

### 6.3 PXD023358 CSV 实测内容

20 列真实二硫键连接肽鉴定表：

```
RUNID PROTID SPOS CLASS DSB CYS CLEV Z SEQ MODS NCE MASS CLUNUM MZ MZDIFF CLURTH CLUAB SCANNUM SCMZSAMP SCMS2RT
```

含结构域归属（VH / CH1）、**半胱氨酸配对**（`HC22-HC97`、`HC147-HC203`）、`_S-S_` 连接肽序列、电荷、实测质量、m/z、质量偏差、保留时间、丰度。

**这使 `disulfide-map` 从预期的 `Blocked` 提升到 `structured-export-analysis` 层级** —— 无需自建二硫键搜索引擎即可驱动「预期连接肽 / 实际连接肽 / 预期连接覆盖 / 异常连接 / 未配对半胱氨酸」的比较。

## 7. 测试结果

| 检查项 | 结果 |
|---|---|
| PRIDE FTP | ❌ 阻断 → 下载器必须走 HTTPS + Range |
| PRIDE HTTPS + Range | ✅ 200 / 206 |
| 4 类格式 magic bytes 实测 | ✅ 全部取得，可直接用于 P6 类型校验 |
| NISTmAb **轻链**交叉比对 | ✅ 两数据集完全一致（213 aa）；自算平均质量 **23127.78 Da 与声明 MW 完全吻合** |
| NISTmAb **重链**交叉比对 | ❌ **不一致**：450 aa（PXD023358）vs 449 aa（PXD063988），第 **360** 位缺一个 **Glu** |
| NISTmAb 重链声明 MW 核算 | ⚠️ 自算全巯基态 49607.28 Da vs 声明 49579.26 Da，**差 +28.02 Da 未解释** |

### 重链序列差异定位

```
PXD023358（450 aa，权威）: …SKAKGQPREPQVYTLPPSREEMTKNQVSLTCLVK…
PXD063988（449 aa，缺陷）: …SKAKGQPREPQVYTLPPSRE MTKNQVSLTCLVK…
                                              ↑ 第 360 位缺 E
```

缺失位置恰好落在 **DOCX 图 5 的 HT35 肽 `EEMTK`** 上——而该图正是「原研 `EEMTK` vs 类似药 `DELTK`」序列差异的范例。

## 8. 局限性

1. **公开 FASTA 会有真实错误**。PXD063988 的 `NIST_HC` 缺一残基已证实。已升级为 P7/P8 硬性验收标准：理论序列必须交叉比对 ≥ 2 个独立来源，并同时核算残基数与声明 MW。
2. **NISTmAb 重链声明 MW 差 +28.02 Da 未解释**。11 个 Cys 全成二硫键最多贡献 −10.08 Da，无法解释该差值。**查清前不得把该 MW 当作理论质量基准。** 这是 V2 Sheet3「实测与理论质量偏差」判定的前提条件。
3. **本步未下载任何大文件**，`raw-data-analysis` 等级仍未获得真实数据支撑；P1 因此标 In progress 而非 Done。
4. **SCIEX WIFF 必须成对**（`.wiff` + `.wiff.scan`），P6 上传校验需支持「多文件构成单个逻辑样本」。
5. **游离巯基无公开数据集**（Ellman 法非质谱数据），P13 只能用合成批次或用户自备 CSV。
6. profile 归并中 4 条「仅展示」方法（Edman 降解、CE-SDS）是方法学固有限制，不是本系统的实现缺口。
7. 数据集覆盖的品种为 NISTmAb / Trastuzumab / Cetuximab / Enbrel，**均非「候选药 vs 参照药」头对头设计**。真正的生物类似药头对头数据（如 DOCX 引用的 CT-P13 vs RMP、HLX03 vs CN-Humira）在公开库中未找到。系统的「候选/参照」对比只能用同一品种不同批次或不同抗体互为对照来演示，**这一点必须在溯源面板中明示**。
