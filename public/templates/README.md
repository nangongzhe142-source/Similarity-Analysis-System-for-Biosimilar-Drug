# BioCompare 标准数据包填写说明

该模板是平台内部交换标准，不是CDE规定的唯一申报文件格式。

建议每个A/B比对任务至少包含：

1. `manifest.json`：研究、样品、批号、制样、仪器、方法和软件版本；
2. 仪器原始文件：保留供应商原始文件，并同时提供可追溯的`mzML`副本；
3. `molecule.fasta`：经确认的轻链、重链理论序列；
4. 分子质量项目：去卷积峰表CSV、代表性原始谱和去卷积谱、参数文件；
5. 序列项目：MS/MS谱、搜索结果`idXML/mzIdentML`、过滤后肽段CSV和覆盖图；
6. 方法与结果报告：PDF/DOCX/XLSX，并标明批号、方法版本、处理条件和复核人；
7. 所有文件应保留SHA-256校验值，转换文件不得替代供应商原始文件归档。

当前演示版只会把`.txt/.dat`两列m/z-强度文件送入UniDec。其他格式仅作为证据附件保存，待OpenMS和格式转换模块接入后再自动处理。
